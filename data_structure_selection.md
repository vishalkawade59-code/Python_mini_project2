# Student Record and Academic Management System

## Data Structure Selection Report

## 1. Data Structure Selection

| Data Structure | Data Stored | Reason for Selection |
|---|---|---|
| String | Student names, departments, addresses, email IDs | Used to store text information |
| List | Student records, subjects, marks, attendance | Used to store multiple ordered and changeable values |
| Tuple | Roll number, registration number, date of birth | Used for fixed groups of values |
| Set | Departments, subjects, student clubs | Used to maintain unique values without duplicates |
| Dictionary | Complete student profile | Used to store related information using key-value pairs |

## 2. Why These Data Structures Work Together

The Student Record Management System combines different Python collections because each data structure has a different purpose.

- Strings store individual text values.
- Lists store collections of values that may change.
- Tuples store fixed groups of information.
- Sets store unique values and automatically avoid duplicates.
- Dictionaries connect different pieces of information using keys and values.

By combining these structures, the system can organize complete student records efficiently.
